🚀 QUICK SETUP (After Installing XAMPP)
========================================

STEP 1: Start Services
----------------------
1. Open XAMPP Control Panel
2. Click "Start" for Apache
3. Click "Start" for MySQL
4. Wait for both to show "Running"

STEP 2: Setup Database
----------------------
1. Open browser → http://localhost/phpmyadmin
2. Click "New" → Create database: egov_db
3. Collation: utf8mb4_unicode_ci → Click "Create"
4. Click on egov_db → Click "SQL" tab
5. Open file: database-setup.sql (in your egov folder)
6. Copy all SQL content and paste in SQL tab
7. Click "Go"

STEP 3: Test Everything
----------------------
1. Open browser → http://localhost/egov/test-api.html
2. Click all "Test" buttons
3. You should see green success messages

STEP 4: View Your Website
----------------------
1. Open browser → http://localhost/egov/
2. Navigate through pages
3. Everything should work!

========================================
🔧 TROUBLESHOOTING
========================================

Problem: "Database connection failed"
Solution: 
- Check MySQL is running in XAMPP
- Database name should be: egov_db
- Username: root
- Password: (leave empty)

Problem: "404 Not Found"
Solution:
- Make sure project is in: C:\xampp\htdocs\egov\
- Restart Apache in XAMPP

Problem: APIs not working
Solution:
- Check file paths are correct
- View browser console (F12) for errors
- Check Apache error log in XAMPP

========================================
💡 USING APIs IN YOUR HTML
========================================

1. Add this to your HTML file:
   <script src="js/api-handler.js"></script>

2. Use JavaScript to fetch data:

   // Get notices
   fetchNotices(1, 10).then(result => {
       if (result.success) {
           // Display notices
           console.log(result.data);
       }
   });

   // Get applications
   fetchApplications().then(result => {
       if (result.success) {
           // Display applications
           console.log(result.data);
       }
   });
